Notifications sans Telegram

Conseil : utilise ntfy pour les notifications push Android. Un « topic » est ton canal d’alerte. Choisis un nom long et difficile à deviner : sur ntfy.sh, les canaux non protégés sont publics.

  1. Installe ntfy sur Android et abonne-toi à un nom de canal aléatoire de 20 caractères ou plus.
  2. En mode hébergé, crée un secret NTFY_TOPIC dans ton dépôt GitHub avec exactement ce même nom.
  3. Dans GitHub, ouvre Actions → Physiolac - surveillance et alertes → Run workflow, puis coche send_test pour recevoir un essai.

Autres choix : e-mail SMTP (SMTP_HOST, SMTP_USER, SMTP_PASSWORD, EMAIL_TO), Discord (DISCORD_WEBHOOK_URL) ou Pushover (PUSHOVER_TOKEN, PUSHOVER_USER). Voir README.md du ZIP pour toutes les étapes.

Sur GitHub Pages, la configuration se fait dans les secrets GitHub, pas ici. Ne publie pas ton canal ni tes mots de passe dans le code.
